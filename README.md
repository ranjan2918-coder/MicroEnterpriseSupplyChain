# Micro-Enterprise Supply Chain & Last-Mile Delivery Optimizer

A comprehensive, full-stack application designed to help micro-enterprises manage their supply chain operations, orders, and last-mile delivery tracking efficiently.

## 🚀 Features

- **Dashboard:** Overview of key metrics, recent activities, and supply chain health.
- **Contacts Management:** Keep track of suppliers, vendors, and customers.
- **Product Catalog:** Manage inventory, product details, and pricing.
- **Order Management:**
  - **Purchase Orders:** Manage inbound stock and supplier orders.
  - **Sales Orders:** Track customer orders from creation to fulfillment.
- **Financials:**
  - **Invoices:** Generate and manage billing.
  - **Payments:** Track incoming and outgoing payments.
- **Delivery Tracking:** Monitor last-mile deliveries, logistics, and delivery status.

## 🛠️ Technology Stack

- **Backend:** Java, Spring Boot
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Icons & Typography:** Font Awesome, Google Fonts (Inter)

## 📁 Project Structure

- `src/main/java/`: Core Java backend application containing Controllers, Services, and Models.
- `src/main/resources/static/`: Frontend web interface (`index.html`, `style.css`, etc.).

## ⚙️ Getting Started

### Prerequisites
- Java Development Kit (JDK 17+)
- Maven
- A modern web browser

### Running the Application

1. Clone the repository:
   ```bash
   git clone https://github.com/ranjan2918-coder/MicroEnterpriseSupplyChain.git
   ```

2. Navigate to the project directory:
   ```bash
   cd MicroEnterpriseSupplyChain
   ```

3. Build and run the Spring Boot backend:
   ```bash
   mvn spring-boot:run
   ```
   *(If you are using the Maven wrapper, use `./mvnw spring-boot:run`)*

4. Open your web browser and access the application at `http://localhost:8080`.
